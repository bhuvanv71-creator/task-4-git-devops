\# Git Workflow Documentation



\## 1. Initialize Repository



git init



Initializes a new Git repository.



\## 2. Check Repository Status



git status



Displays modified and untracked files.



\## 3. Add Files



git add .



Stages files for committing.



\## 4. Commit Changes



git commit -m "Initial project commit"



Saves changes in Git history.



\## 5. Create Branch



git branch dev



Creates a development branch.



\## 6. Switch Branch



git switch dev



Switches to the development branch.



\## 7. Push Changes



git push origin dev



Uploads local commits to GitHub.



\## 8. Pull Latest Changes



git pull origin dev



Downloads and integrates remote changes.



\## 9. Merge Branch



git merge feature/documentation



Merges feature changes into the current branch.



\## 10. Git Tags



git tag -a v1.0 -m "First release"



Creates a version tag.
